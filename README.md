##Digital Clock

A simple, web‑based digital clock built with HTML, CSS, and JavaScript. 
The clock displays the current time in real‑time using JavaScript’s Date API and updates every second.

##Features

Real‑time time display
Automatic second‑by‑second updates
Clean, minimalist UI
Lightweight and fast

##How It Works

The clock uses JavaScript to:
Retrieve the current time using the Date() object
Format hours, minutes, and seconds
Update the display every second using setInterval()

**Tech Stack

HTML — structure
CSS — styling
JavaScript — time logic and updates

##Project Goals

This project was created to practice:
DOM manipulation
Real‑time updates
Clean UI design
Basic JavaScript functions
